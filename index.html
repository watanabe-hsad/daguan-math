    同步进度

    本站不能直接连大观园接口。推上去、拉回来都在官网用 F12 控制台跑一次脚本。

    1. 确认要写上去的内容

      只会推送你在本站标记过的题，未开始的不会覆盖大观园已有进度。

      • 已掌握 0
      • 易错 → 不熟练 0
      • 学习中 → 不熟练 0

      还没有掌握标记，先在题目上点「已掌握 / 易错 / 学习中」。

    2. 复制一次

      脚本里已经带上当前进度。

    3. 打开并登录澄潇宇大观园

      新标签打开官方站，确认已经登录。

      https://cxyonly.fans/math

    4. 按 F12，点「控制台」

      • 键盘 F12（Mac 笔记本多为 fn + F12）。
      • 在开发者工具里点顶部 Console / 控制台，不要留在 Elements。
      • 必须在大观园这一页打开，不要在本站打开。
      • 若提示不允许粘贴，先输入 allow pasting 回车，再粘贴。

    5. 粘贴，回车，输入 SYNC

      弹出确认框后输入 SYNC 才真正提交。默认只增不减。

    1. 复制导出脚本

      这份脚本在大观园页面运行，把那边的掌握标记收成一份进度包。

    2. 打开并登录澄潇宇大观园

      https://cxyonly.fans/math

    3. 按 F12，点「控制台」，粘贴回车

      • 键盘 F12（Mac 笔记本多为 fn + F12）。
      • 点 Console / 控制台。
      • 若不能粘贴，输入 allow pasting 回车后再贴。
      • 成功后会自动复制进度 JSON，并下载一份备份文件。

    4. 回到本站，写入本地记录

      优先点「从剪贴板导入」。不行就粘贴到下面，或选择刚下载的 JSON。

      只会更新大观园里已有标记的题：掌握 → 已掌握，完全不会 → 易错，不熟练 → 学习中。本站多出来的标记不会被删掉。
    PDF 预览

    打印对话框里，目标选「另存为 PDF」，纸张 A4，边距默认即可。建议文件名见预览封面。
