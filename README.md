# 大观园 · 刷题

澄潇宇大观园会不定期维护或发版，原站这时打不开。这个仓库是那段空窗里用的静态刷题页：题目整理自大观题库，浏览器打开就能做，没有账号，也没有服务器。

它不是原站的完整拷贝，也不打算长期取代原站。维护结束，进度可以按页里的步骤写回大观园。

在线：[https://hsad.xyz/daguan-math/](https://hsad.xyz/daguan-math/)  
备用：[https://watanabe-hsad.github.io/daguan-math/](https://watanabe-hsad.github.io/daguan-math/)

不要用 `file://` 直接双击 `index.html`，分类和题目都是 JSON，需要 HTTP。本地可以：

```bash
python3 -m http.server 8765
```

浏览器打开 http://127.0.0.1:8765/

## 刷题

左侧是分类树。点进一章，默认 **列表模式**：往下滚就是下一题，每题自己展开答案、改掌握状态。顶栏可切 **单题模式**（一次一题）。

掌握四档：未开始、学习中、已掌握、易错。侧栏「未掌握」「易错题」按标记筛。搜索走题号、来源、题干。完整 / 核心、仅核心、未掌握是另外几道筛子。

单题模式快捷键：`←` / `→` 换题，`A` 答案，`1`–`4` 选项。

进度写在本机 `localStorage`，换电脑或清站点数据会丢。侧栏可以清掉本地进度；同步面板里也能下载一份 JSON 备份。

题大约六千道。配图默认从大观园的 `question-assets` 拉；接口挂了的话，图会裂，题目和解析还在。要改图床，编辑 `data/manifest.json` 的 `asset_base_remote`。

## 导出 PDF

卡片左侧方框勾题。刷题页上方可以全选当前列表或清空。顶栏 **导出 PDF** 会先出预览（封面、题干、选项、答案、解析，公式是 KaTeX），再调用浏览器打印。

打印对话框里把目标改成「另存为 PDF」，纸张 A4 即可。

范围也可以是当前整份列表、未掌握、易错、已掌握，不必先勾。一次不宜太多：八十题以上会先确认，上限 250。大章请按小节分批。

## 同步进度

本页是 GitHub Pages，浏览器不准从这里改大观园账号，所以不能一键对打。侧栏 **同步进度** 分两向，都是：复制脚本 → 打开已登录的 [大观园](https://cxyonly.fans/math) → `F12` 打开开发者工具 → 点 **Console / 控制台** → 粘贴。

Mac 笔记本上 `F12` 常常要加 `fn`。必须在大观园这一页开控制台，在本站开没有用。若提示不能粘贴，先输入 `allow pasting` 回车，再贴脚本。

**写到大观园**  
脚本里已经带上本机标记。粘贴后按提示输入 `SYNC` 才提交。对应关系：已掌握 → 掌握；易错、学习中 → 不熟练。未开始的题不会去覆盖原站。默认只增不减。

**拉回本站**  
先复制「导出脚本」，在大观园控制台跑完，进度 JSON 会进剪贴板并下载一份文件。回到本站点「从剪贴板导入」，或选文件 / 贴进文本框再写入。对应：掌握 → 已掌握，完全不会 → 易错，不熟练 → 学习中。本站多出来的标记不会被删。

原站若仍在维护，脚本会失败。把备份留下，等恢复再做后半段。

## 数据
